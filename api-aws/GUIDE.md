# KPIダッシュボード API　はじめての方へ

KPIダッシュボードの数字（万垢率・ファネル・生徒の一覧など）を、URLを開くだけで取り出せる仕組みです。
ダッシュボードを開かなくても、ブラウザ・Claude・スプレッドシートなどから最新の数字を見られます。

---

## 1. 必要なもの（管理者からもらう）
- **URL**：`https://tgclrrnx555ujvfuooneocoqoa0ztioj.lambda-url.ap-northeast-1.on.aws/`
- **読み取り用の合言葉**（READ_TOKEN）

> 合言葉は、生徒の名前まで見られる大事なものです。人に転送したり、GitHub・Slackの公開チャンネルに貼ったりしないでください。

---

## 2. まず開いてみる
ブラウザのアドレス欄に、次のように入れて開きます。

```
URL?token=読み取り用の合言葉
```

こんな文字が出れば成功です。

```
{"updatedAt":"2026-11-06T03:37:10.814Z","cohorts":["2026/10","2026/11",...],"types":[...],"history":[...]}
```

| 項目 | 意味 |
|---|---|
| updatedAt | データが最後に更新された日時（世界標準時。日本時間は＋9時間） |
| cohorts | 取り出せる卒業月の一覧 |
| types | 取り出せるデータの種類（下の表） |
| history | 過去のデータが残っている日付 |

---

## 3. 取りたいデータを選ぶ
URLの最後に `&type=種類` を付けます。

| やりたいこと | 付けるもの | 例 |
|---|---|---|
| 卒業月ごとの万垢率・5000/3000/1000人以上率を見たい | `&type=summary` | `URL?token=合言葉&type=summary` |
| 1つの卒業月をくわしく見たい（ファネル・属性・生徒分類） | `&type=cohort&ym=2026/11` | |
| 1つの卒業月の生徒一覧がほしい | `&type=students&ym=2026/11` | |
| コーチング（開始月ごと）のKPIを見たい | `&type=coaching` | |
| プログラム完了率（60日以内など）を見たい | `&type=program` | |
| 生徒ごとのプログラムの進み具合を見たい | `&type=programs` | |
| 月次レポートのデータを見たい | `&type=monthly` | |
| 全部まとめてほしい | `&type=all` | （データが大きいので注意） |
| 過去のある日の数字を見たい | 上のどれかに `&date=2026-11-04` を足す | |

- `ym` は卒業月です。`2026/11` のように「年/月」で書きます。
- 表示されるのはJSON（プログラム用の文字の形式）です。人が読むなら、下の「Claudeに読ませる」が一番かんたんです。

---

## 4. よくある使い方

### Claudeに読ませる（おすすめ）
Claudeに、URLと聞きたいことを一緒に送ります。
```
このデータを読んで、11月卒業の今の状況を表にまとめて
URL?token=合言葉&type=cohort&ym=2026/11
```

### スプレッドシートに入れる
Google スプレッドシートの「拡張機能 → Apps Script」で、URLを読み込む仕組みを作れます（必要なら管理者に相談）。

### 同僚に見せる
`&type=summary` のURLを送れば、ブラウザで開くだけで数字が見られます。
（合言葉が入ったURLなので、送る相手は社内の必要な人だけにしてください）

---

## 5. うまくいかないとき

| 表示 | 原因と対処 |
|---|---|
| `読み取りの合言葉が違います` | 合言葉が間違っています。コピーの前後に空白が入っていないか確認 |
| `まだデータがありません` | 管理者がまだダッシュボードを開いていません。管理者に連絡 |
| `ym=2026/10 のように卒業月を指定してください` | `cohort`・`students` は `&ym=` が必要です |
| 数字が古い | データは**管理者がダッシュボードを開いたとき**に更新されます。`updatedAt` で更新日時を確認 |

---

## 6. 知っておいてほしいこと
- 数字はダッシュボードと同じ計算です（卒業済みの月は卒業日まで、在籍中は今日まで）。
- データが新しくなるのは、管理者がダッシュボードを開いたときです（週次レポートを作るタイミングで更新）。
- 合言葉を変えたいとき・おかしいと思ったときは、管理者に連絡してください。
